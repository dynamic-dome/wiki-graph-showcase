# wiki-graph-showcase

Public 3D-Knowledge-Graph-Showcase for dome-dynamics (wiki.dynamic-dome.com). Two datasets, rendered with three.js: the competence graph on agentic engineering (default, from `kompetenz-wiki`) and a curated astrophysics nebula (`physik-weltall-wiki`). Two themes (Crab Nebula + Dynamic Dome), Gold-Mode slider.
